# 26.2 egress bytes accounting gate

`crates/pumpkin/src/net/java/mod.rs` の Java egress は、単一 FIFO の `OutgoingPacket` を bytes の所有者に
した。enqueue 時に `try_reserve_pending_bytes` が `MAX_PENDING_BYTES` を checked CAS で予約し、packet の
`Drop` が completion waiter 通知と同時に一度だけ checked 減算する。deferred queue、FIFO receiver の
sender-closed、frame/write/flush error、repeated `close` の各破棄経路を同じ所有権へ集約し、saturating
減算で不整合を隠さない。close 後の enqueue は gate 内でも拒否する。

確認した回帰:

- `deferred_close_releases_bytes_and_unblocks_send_packet_now`
- `concurrent_close_and_enqueue_has_no_accounting_leak`
- `sender_closed_releases_packet_and_unblocks_waiter`
- `writer_frame_error_releases_bytes_and_unblocks_waiter`

`--locked`）:
