### 3. 起動時に確認した狭い world 不具合と修正

最初の実 Pumpkin 起動（port `25565`、pre-fix binary）では、server log に次が出た。

```text
No level.dat in world, creating a new world with seed ...
ERROR Failed to save level.dat: Info not found!
```

根因は `WorldInfoError::InfoNotFound` が `std::io::ErrorKind::NotFound` の変換であり、初回 `world/` がまだない状態で `AnvilLevelInfo::write_world_info` が `level.dat_new` を作成していたこと。`existing_level_dat_root` 自体は missing `level.dat` を許容するが、親 directory の作成は行っていなかった。

検証で確認した最小修正は、`write_world_info` の version stamping より前に次を実行することだった。

```rust
std::fs::create_dir_all(level_folder)?;
```

修正後の新規 run directory では同じ `Failed to save level.dat: Info not found!` は出ず、`world/level.dat` が生成された。

### 5. 正常終了、成果物、残 process

harness の socket close 後、controller の redirected stdin に `stop\n` を送った。最終 server は次で終了した。

- shutdown action: `stdin-stop`
- server exit code: `0`
- controller status: `C:/Temp/pumpkin-26_2-next-logs-fixed/controlled-server.status.json`
- log は `Stopped accepting incoming connections` → `Starting save` → `Completed save!` → `The server has stopped.` の順。
- `127.0.0.1:25567` は解放済み。
- `world/level.dat`: `482` bytes、SHA-256 `DBCDE3466867DFDAB15E583DD68A6785F914F390F40EF76D6C0589BBBD1E01FD`
- server stdout: `3,407` bytes、SHA-256 `BE2F77C192D11E194A5C8FC1348773E18A2D6F13D0A8B57533AFF55384990BE1`
- server stderr: `5` bytes、SHA-256 `F01A374E9C81E3DB89B3A42940C4D6A5447684986A1296E42BF13F196EED6295`

比較のため、修正前の port `25565` 試行も status/login はともに終了コード `0`（status `protocol=776/status_pong=pass`、login `compression_threshold=256`, `configuration_packets=35`, `keepalives_replied=1`, `play_packets=10566`）だったが、初回 `level.dat` save error の後、redirected stdin のない起動方法だったため `Stop-Process -Force` で停止した。この pre-fix 試行の停止は正常終了ではない。最終判定と正常終了の証拠は修正後 port `25567` の controlled run と分離して扱う。

最終確認の `Get-Process -Name cargo,rustc,rustup,pumpkin,java` は該当なし、ports `25565/25566/25567` は listen なし。途中で観測された別 toolchain の cargo/rustc/rustup は停止操作をせず、最終確認時には消滅していた。既存 server process は停止していない。

## Unconfirmed / Limitations

- vanilla 26.2 client（Java 25）の実接続は未実施。今回の success は synthetic protocol harness から実 Pumpkin への TCP smoke であり、実機 client compatibility の証拠ではない。

- online-mode/encryption、resource-pack response、chat signing、mod/plugin、Bedrock bridge、完全な gameplay は未確認。
- fixed run で `level.dat` の生成・正常保存は確認できたが、公式 vanilla 26.2 world との比較、旧版 world の実変換、実 Anvil round-trip の全 payload 互換はこの試験の範囲外。
- server stdout には初回 world creation の通常 warning `No level.dat in world` が残るが、修正後は `Failed to save level.dat: Info not found!` が消えた。
