### 縦断読解（コード変更前）

優先順に次を読んだ。

1. **spawn → position ack**
   - `crates/pumpkin/src/world/mod.rs::World::send_world_info`
   - `crates/pumpkin/src/entity/player.rs::Player::request_teleport`
   - `crates/pumpkin/src/net/java/play/confirm_teleport.rs::JavaClient::handle_confirm_teleport`
   - 初期 Join では `CPlayerSpawnPosition`、world info、chunk、teleport の順が既存実装にある。
   - `request_teleport` は position を entity に保存し、`awaiting_teleport=(id, position)` を設定する。確認 packet の処理は network 所有範囲のため変更しない。

2. **movement**
   - `crates/pumpkin/src/net/java/play/player_position.rs`
   - position/rotation packet は client-loaded と teleport ack を待ち、NaN/非有限値を拒否し、entity position/rotation、chunk watcher、fall、他プレイヤーへの移動通知を更新する。ネット範囲の TODO（速度検証等）は推測修正しない。

3. **block break/place**
   - `crates/pumpkin/src/world/mod.rs::World::break_block`
   - `crates/pumpkin/src/world/mod.rs::World::set_block_state`
   - `crates/pumpkin/src/net/java/play/player_action.rs`
   - `crates/pumpkin/src/net/java/play/use_item_on.rs`
   - break は reach、spawn protection、event、loot、waterlogged state、block callbacks、client block update の既存経路を持つ。place は network crate 所有の handler から `World`/block registry に接続されるため、今回そこを編集しない。

4. **inventory synchronization**
   - `crates/pumpkin/src/entity/player.rs::Player::sync_inventory_to_client`
   - `Player::sync_hand_slot`、`Player::damage_item_in_slot`、`Player::drop_held_item`、`Player::swap_item`
   - `crates/pumpkin-inventory/src/player/player_inventory.rs::PlayerInventory::swap_item`
   - **確実な欠陥を1件修正:** `Player::swap_item` は main/off-hand のサーバー状態と他プレイヤー向け equipment を更新する一方、inventory slot packet を送っていなかった。`PlayerInventory::swap_item` は listener を通さず直接 main inventory と equipment map を書くため、Java client の inventory slot表示が交換前のまま残る経路があった。
   - `crates/pumpkin/src/entity/player.rs` の `Player::swap_item` で、選択 hotbar slot (`0..=8`) と off-hand slot `40` の `CSetPlayerInventory` を送信し、`sync_inventory_to_client` も実行するよう最小修正した。既存の equipment broadcast は維持した。
   - 回帰 test `entity::player::tests::hand_swap_sync_covers_selected_and_off_hand_slots` と `entity::player::tests::player_inventory_swap_changes_the_two_synced_slots` を追加した。

5. **chat**
   - `crates/pumpkin/src/net/java/play/chat_message.rs`
   - 26.2 の chat signing/validation は network 所有範囲で、allow-chat-reports の分岐と system/secure broadcast の既存経路を確認した。未確認の packet/spec を追加しない。
