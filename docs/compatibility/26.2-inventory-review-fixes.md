# Java 26.2 inventory review fixes

## Findings

- **INV-T1 fixed in the owned crafting handler.** `ResultSlot::match_recipe` now treats the generated map-cloning transmute as one filled-map input slot plus `1..=8` occupied map material slots. Result count is `base + material_slot_count`; a stack count inside one material slot is not used as a multiplier. The input slot remains the only component-copy source, so `map_id` is preserved.
- Other generated transmute recipes retain their existing one-input/one-material (`2` occupied slots) contract. No broad multiplier was inferred for recipes whose generated model does not contain the 26.2 `material_count` fields.
- **INV-T4 fixed in the Java close path.** `SCloseContainer.window_id` is passed from the Play dispatcher to `JavaClient::handle_close_container`. The handler compares it with the active `ScreenHandler::sync_id()` and returns without invoking `Player::on_handled_screen_closed()` on mismatch. No speculative resync packet was added.
- Existing INV-01 shift-click/remainder changes were preserved; cake remainder behavior was not changed by this fix.

## Migration / Investigation Notes

- The generated `CraftingTransmute` model in `crates/pumpkin-data/src/generated/recipes.rs` does not expose the map recipe's JSON bounds/flag. The owned, narrow implementation therefore recognizes only the generated filled-map result as the special `1..=8` slot-count case; it does not alter generated data or manifest files.
- For a 3x3 crafting handler, nine occupied grid slots can be represented. The valid maximum is one filled-map input plus eight map material slots. The invalid nine-material fixture fills all nine grid slots with maps and has no input, so it verifies recipe failure through the handler without fabricating a tenth UI slot.
- Stacked material is deliberately tested as one occupied slot: an eight-map stack yields result count `2` and leaves seven maps after one craft.
- Stale close handling is rejection-only. It does not close the current handler and does not add an unverified resynchronization packet.
- `crates/pumpkin-inventory/src/player/player_screen_handler.rs` existing INV-01 and cake tests were retained.
