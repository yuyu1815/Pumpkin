### Blockers と offline synthetic fallback

現時点のblockerは次の3件である。

1. 公式 client/server の利用権・EULA同意が明示確認されていない。
2. inspected local locations に公式 `server.jar` がなく、期待値 `60,894,273` bytes / SHA-1 `823e2250d24b3ddac457a60c92a6a941943fcd6a` を実物で検証できない。
3. inspected locations に既存 `eula.txt` がない。別 directoryから複製してはいけない。

Java 25 bundled runtime と client JARのhashは利用可能だが、これはblockerを解消しない。従って今後無人で実施できる代替は、**公式 clientを起動しない offline synthetic比較**に限る。並列担当が作成した専用 server binaryを repo外の fresh run directoryで使用し、既存の `protocol776_harness.py --mode login --strict-play` を実行する。ただし結果は `strict_play_validation=pass` / `real_client_compatibility=not_claimed` として保存し、vanilla接続済みへ昇格させない。
