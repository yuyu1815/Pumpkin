### Inventory remainder / transmute

- `player::player_screen_handler::tests::cake_pickup_returns_bucket_remainders_and_close_returns_cursor`: 初回 exit `101`、`0 passed / 1 failed`。
- 根因: player inventory handler は 2x2 grid なのに、fixture が 3x3 cake recipe を player handlerにも配置していた。production expected値の書換えではなく、valid 3x3 crafting-table caseだけを検査するよう test を修正した。

- `player::player_screen_handler::tests::map_transmute_preserves_components_multiplier_and_requires_material`: exit `0`、`1 passed / 0 failed`。`map_id=42` component、result count `2`、input消費、filled_map + filled_map no-opを確認。

## Migration / Investigation Notes

All Cargo commands used:

```text

CARGO_TARGET_DIR=C:/Temp/pumpkin-target-26_2-next
CARGO_INCREMENTAL=0
CARGO_PROFILE_DEV_DEBUG=0

--locked
```

The `--list` commands were used before exact test execution so a zero-test success could not be mistaken for a pass. No expected result was weakened to make a test pass. The functional source edit during this gate was the inventory test fixture correction described above; the remaining inventory source edits were formatter-only normalization. The correction aligns the test with the existing 2x2 player / 3x3 crafting-table slot contracts.

Capacity checks reported C: free `242,869,661,696` bytes before the optional build and `220,049,575,936` bytes at final inspection; both are above the `30 GiB` stop threshold. `cargo fmt --package pumpkin-inventory -- --check`, `cargo fmt --package pumpkin -- --check`, and `git diff --check` exited `0` (`git diff --check` emitted only existing LF→CRLF warnings). Cargo logs were written only under `C:/Temp/pumpkin-validation-26_2/`; no repository log was added. The PowerShell `Get-FileHash` command was unavailable in the host shell, so the recorded binary SHA-256 was obtained with `sha256sum`.

Not verified by this gate: vanilla client acceptance, resource-pack download with a real client, stateful TCP configuration fuzzing, inventory full/partial remainder drop lifecycle beyond the tested cake close path, map cloning material counts `2..8`, `map_extending.json`, scheduler unload/shutdown save end-to-end, chat signing, and complete 26.2 gameplay compatibility.
