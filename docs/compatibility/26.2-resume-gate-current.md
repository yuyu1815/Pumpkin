## Latest remediation checkpoint

### G chat lifecycle / cleanup

- `PlayerRemovalReason::{Disconnect,DimensionTransfer}`で従来の `fire_event == disconnect` bool仮定を型分離した。Disconnectだけがchat sidecarをretire/clearし、transferはchainを保持する。
- `Player::chat_owner_generation`はallocation pointerではないmonotonic `u64` token。state storeはowner mismatchを拒否し、disconnect時のretired tombstoneでlate session update/verifyの再作成を拒否する。
- session update、secure verify、disconnect retirementは`chat_lifecycle` mutexで直列化。same-UUID old removalはnew stateをclearせず、world tab-list remove、server listing count/sample、UUID-keyed entity observer cleanupもreplacementを保護する。
- state tests: **11 passed / 0 failed / 278 filtered out**。late old generation recreation、same-session replacement、matching cleanupを含む。

### E real TCP
