2. **level.dat の旧版保護と現行版保護は実装されている。**

3. **Anvil/NBT の level 情報保存・再読込み用 fixture テストは既存コードにある。**

### 欠陥判定

- **確実な小さい欠陥を 1 件修正した。**
  - `crates/pumpkin-world/src/world_info/anvil.rs` の `AnvilLevelInfo::write_world_info` は、既存の `level.dat` がある場合も `level.dat_new` から `level.dat` への `std::fs::rename` の結果を捨てていた。
  - Windows の `rename` は既存 destination を置換しないため、通常の再保存で更新が失敗しても `Ok(())` を返し、古い `level.dat` と残った `level.dat_new` を残す確実な欠陥だった。
  - `replace_level_dat` を追加し、通常の rename が `AlreadyExists` の場合だけ destination を削除して再 rename する。その他の rename error は `WorldInfoError` として返す。
  - 回帰テスト `rewrite_level_dat_replaces_existing_destination` を追加し、再保存後に `level.dat_new` が残らず、再読込みの DataVersion が `4903` になることを検査する。
- 上記以外に、確実性のある小さい欠陥は確定しなかった。不要な推測修正は行っていない。
- 確認した「未検証」は欠陥の確定ではない。特に canonical 26.2 の実 vanilla world と Anvil chunk payload を使った検査がないため、互換性を宣言できない。
