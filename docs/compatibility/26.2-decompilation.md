# Minecraft Java 26.2 server の外部 decompilation 環境

Warden の挙動を一次 artifact から読めるようにするための再現手順である。公式 JAR と生成 Java source は **Pumpkin repository に保存しない**。

## 必要条件

- bash、`curl`、`unzip`、`sha1sum`、`sha256sum`
- **JDK 21**（helper は別 major version を拒否する）
- CFR `0.152`。出力先の `cache/cfr-0.152.jar` がなければ、CFR 公式配布 URL から取得する。既存の JAR を使う場合は `CFR_JAR=/absolute/path/cfr-0.152.jar` を指定する。

## 実行

repository root から、必ず repository 外の出力先を指定する。

```sh
bash tools/decompile-minecraft-26.2.sh C:/Temp/pumpkin-minecraft-26.2-decompiled/
```

対象が増え、完全 source tree が必要になった場合だけ `--full` を付ける。

```sh
bash tools/decompile-minecraft-26.2.sh C:/Temp/pumpkin-minecraft-26.2-decompiled/ --full
```

通常実行は Warden 調査に必要な `SpawnUtil`、`SpawnUtil$Strategy`、`Mob`、`Warden`、`WardenSpawnTracker`、`SculkShriekerBlock`、`SculkShriekerBlockEntity` に限定する。`--full` は inner server JAR 全体を CFR へ渡す。script は `realpath -m` で存在しない末端も含めた出力先を先に正規化し、正規化に失敗した場合は安全側で停止する。正規化後の出力先が repository root またはその配下なら、mkdir や書き込みより前に拒否し、ディレクトリを残さない。出力先が既に存在する場合は空ディレクトリだけ許可し、ファイルまたは内容が1つでもある場合は実行を拒否する。既存データは削除・上書きしない。再実行には caller が所有する新しい出力先を指定するか、既存出力先を caller 自身が空にしておくこと。

## artifact の固定値と検証

helper は Mojang の manifest から `id=26.2` / `type=release` の metadata URL と SHA-1 を取得し、その SHA-1、metadata が pinned server URL/hash を含むことを確認してから artifact を取得する。metadata は Mojang が再発行し得るため、実行時に使った URL/SHA-1 は外部 output の `README.md` に固定記録する。outer/inner JAR の content hash は下表の値に固定する。

| 対象 | URL / entry | 検証値 |
|---|---|---|
| version manifest | `https://piston-meta.mojang.com/mc/game/version_manifest_v2.json` | `id=26.2` / `type=release` entry |
| 26.2 metadata | manifest が示す official URL | manifest entry の SHA-1 |
| outer server bundle | `https://piston-data.mojang.com/v1/objects/823e2250d24b3ddac457a60c92a6a941943fcd6a/server.jar` | SHA-1 `823e2250d24b3ddac457a60c92a6a941943fcd6a` |
| nested server implementation | `META-INF/versions/26.2/server-26.2.jar` | SHA-256 `183c0499c5f855570ee487dd38e141a53f0121f83a0b07a3bac2d8b6698823e8` |

成功時は output root の `README.md` に実行時刻、mode、公式 URL、全 hash、CFR version/JAR SHA-256、Java version を記録し、`INDEX.md` に source path と `rg` コマンドを出力する。JAR は `cache/`、generated Java は `src/` にだけ置かれる。

Mojang artifact と decompiled source は再配布物として repository に追加しない。`assets/NOTICE.md` の帰属・license 境界も維持する。
